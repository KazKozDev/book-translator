Choose a model for each role

Tolmach keeps translation, refinement, glossary preparation and quality checks separate, so every stage can use the local model best suited to it.

LLMs

Keep every role independent: the judge does not grade its own output, and a translation-only model is never used for instruction or editing.

Used only for Start.

Used only for Continue, the editing pass after the draft is ready.

Rules on every edit Refinement proposes: it sees the source and both versions, twice with the order swapped, and the edit is kept only if it wins both times. Pick a model clearly larger than Refinement. A model grading its own edits answers by which version came first rather than by what it says, the two orderings then disagree, and every fix is thrown away — the pass looks like it ran and changes nothing.

Used only for Prepare, and only to rule on identity: whether two source forms name one entity, which spelling variants belong together, and which the clustering got wrong. This is reasoning about the document rather than translation, so it is the role that repays a larger model — a small one gives two different characters the same rendering.

Used only for Prepare: proposes the target-language rendering and the enforcement mode for each name the entity pass agreed on.

Used for LLM judge and the backtranslation diagnostic. Translation-only TranslateGemma models are excluded.

Neural models

These models are chosen by the application for their specific task, not from the Ollama list. They install with the app, and each downloads its weights the first time the feature that needs it is used.

GLiNER multilingual NER

Finds candidate names and entities during Prepare. Model page on Hugging Face.

BGE-M3
