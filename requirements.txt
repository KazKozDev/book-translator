# What the app needs to run, and nothing else. The launcher installs this file
# on every start, so a package that is not required to translate a book belongs
# elsewhere: test and lint tooling in requirements-dev.txt.
#
# The quality models used to live in separate optional files. They no longer do:
# a test that reports "dependency not installed" instead of a number is a test
# nobody runs, and torch — the one genuinely heavy thing — is pulled in by
# sentence-transformers regardless. Model weights are still fetched on first
# use, not at install time.

# already here through sentence-transformers, so this adds lightning and a few
# small packages, not a second deep-learning stack; the multi-GB checkpoint is
# still downloaded on demand, the first time the test is actually run.
#
# 2.2.7, not the 2.2.2 this started on: 2.2.2 requires sentencepiece <0.2.0,

# and Windows user, not just CI. 2.2.4 onwards asks for sentencepiece >=0.2.0,
# which has wheels everywhere.
unbabel-comet==2.2.7
